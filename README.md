# DevOps CI/CD Final Project

## Project Name
DevOps CI/CD Pipeline Implementation

## Description
This project demonstrates Continuous Integration and
Continuous Delivery using GitHub Actions, Tekton,
and Red Hat OpenShift.

## Technologies
- GitHub Actions
- Tekton Pipelines
- OpenShift
- Git
- Docker

## Project Objectives
- Automate code testing using GitHub Actions.
- Implement CI/CD pipelines using Tekton.
- Deploy applications using OpenShift.
- Monitor and verify successful deployments.
